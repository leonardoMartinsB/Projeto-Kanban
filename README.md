## ✨ Sobre o Projeto

Este projeto é um **Quadro de Tarefas Kanban** interativo, desenvolvido com **HTML, CSS e JavaScript**. Ele foi criado para ser uma ferramenta simples e eficiente para a **gestão visual de tarefas e projetos**.

A aplicação permite que o usuário organize suas tarefas em colunas, com a funcionalidade de **arrastar e soltar (drag and drop)**, facilitando o gerenciamento de atividades de forma intuitiva. É uma excelente demonstração de como utilizar JavaScript puro para criar interações complexas em uma página web.

🔹 Principais destaques:

* ✅ Funcionalidade **drag and drop** para movimentação de tarefas
* ✅ Estrutura organizada e interativa com **HTML, CSS e JS**
* ✅ Design minimalista e focado na usabilidade
* ✅ Ferramenta ideal para aprender conceitos de manipulação do DOM e eventos do navegador

## 🛠️ Tecnologias Utilizadas

* **HTML5** → Estrutura do quadro e dos cartões de tarefas
* **CSS3** → Estilização das colunas e dos cartões
* **JavaScript (Vanilla)** → Lógica da funcionalidade de arrastar e soltar e manipulação do DOM
